# Cursor Rules — delegated to agent-toolkit

Agent rules are distributed by [agent-toolkit](https://github.com/ulises-jeremias/agent-toolkit).

```bash
dots-skills install-toolkit
# or: brew / AUR agent-toolkit-bin / GitHub V binary / uv tool install --force 'agent-toolkit-cli>=1.11.0'
agent-toolkit install
```

See `docs/AGENT_TOOLKIT.md`.
