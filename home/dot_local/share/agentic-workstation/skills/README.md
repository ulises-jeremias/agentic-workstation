# Skills — delegated to agent-toolkit

This directory is intentionally empty in the thin workstation.

All cross-domain skills, agent personas, and loop templates,
and tool profiles (7) are distributed by [agent-toolkit](https://github.com/ulises-jeremias/agent-toolkit). Workstation-specific orchestration skills remain in this directory.

Install via:

```bash
dots-skills install-toolkit
agent-toolkit install
```

The `SKILL.md` catalog is provided by the toolkit at runtime and
discovered via `agent-toolkit` — not embedded in this repository.

See `docs/AGENT_TOOLKIT.md` for integration details.
